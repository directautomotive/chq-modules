Estimate Pills

Version 1 · Oct 10, 9:50 AM · what the app shows today (5.255)

Every pill the Review / Edit Estimate window can show, in the app's colors, with when it shows. Green = read fine. Yellow = look at this. Red = stop and decide. Notice pills longer than about 56 letters end in "…"; hover shows the whole sentence.

The pills sit next to the title, left to right: what read it, then the notices.

1. What read the file

Always first, right after the title. One of these.

Read As CCC ONEThe file is a CCC ONE estimate (it has "Workfile ID", "Estimate of Record" or "Supplement of Record").
Read As MitchellThe file is a Mitchell estimate (it says Mitchell, UltraMate or WorkCenter).
Read As AudatexThe file is an Audatex estimate (Audatex, AudaExplore or Solera).
Read As CCC ONE · Checked By AIKnown system, and the AI reader also read the pages and checked the figures.
Read By AIUnknown system, but the AI reader filled the boxes.
Format Not Recognized. Check Every Figure.Unknown system and no AI read — every box is a best guess.

2. Already on the board?

Checked against every month by claim number and VIN (5.255).

Already On The Board: August 2026Same claim number as a job already on the board ("260827376" and "260827376-1" count as the same). Title says "— Duplicate"; buttons: Update This Job / Add as New Row.
Same Car, New Claim · August 2026 (Claim 260827376)Same VIN, different claim number — the car came back with a new accident. Not a duplicate; it's added as its own row.

3. How the file was read

Yellow notices about the file itself. Hover any of them for the whole sentence.

This PDF is pictures of pages, not text, so it was read…The PDF is pictures (photo estimate, scan) and was read page by page like a scan. Check every box against the preview.
This PDF is pictures of pages; it was read by AI from the…Pictures, read by the AI reader instead.
2 fields were read two different ways — marked yellow…The built-in reader and the AI reader disagreed on some boxes; those boxes are yellow.
The AI reader couldn't be reached (…), so only the…AI reader offline or failed; only the built-in reader filled the boxes.
This PDF doesn't seem to contain readable text (it may…No text in the file and the picture reader couldn't load (no internet).
This PDF doesn't seem to contain readable text, and…No text, and reading the pictures found nothing usable — fill in by hand from the preview.
The saved copy of this PDF couldn't be found, so there's…Edit Estimate on a job whose saved PDF is missing — the boxes are still your saved values; use Replace to attach it again.
Could Not Read This File. Fill In By Hand.The reader crashed on this file.

Check Claim NumberThe claim number doesn't look like this carrier's usual shape. Click it to say it's right — the app remembers that shape. (Same idea for any other box with a format check.)
