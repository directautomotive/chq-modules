Customers Module

One list of every customer, with phone, email, address and cars, kept in Settings. When you fill out a job you type the name the normal way; nothing looks anything up until you press Search. Demo data only, every name and number below is made up.

Where The List Lives

Settings › CustomersIn CollisionHQ Settings, next to the other lists. Search it, see each customer's phone, email, address, cars and how many jobs.
Built from the jobs you already haveEvery job on the board already carries a name, phone and address. The list is made from those once, then each saved job adds to it. Nothing to type twice.
Saved with the jobsSame online storage as the board, so the same list is on every computer and phone the shop signs into.

Past Jobs

Rules in this module: nothing is looked up while you type. Search matches the first name exactly and the last name by its first letters, so "Taya J" finds Taya Jones but "Tay" alone finds nobody. If the phone box already has a full 10-digit number, Search also checks it. Picking a result fills phone, email and address; it never fills anything by itself. If nobody matches, it is a new customer and Save adds them to the list.
